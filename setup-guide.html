02

Opening the app All plans

A
Open directly on your device
Download Servly_Expenses.html to your device. Double-click it — it opens in your default browser. Works completely offline from this point on.
Best for: Single device, no team sharing needed
B
Host on GitHub Pages (free)
Upload to a free GitHub repository and get a public URL — e.g. yourbiz.github.io/expenses. Any phone, tablet, or desktop can open it. See Section 04 for full steps.
Best for: Teams, multiple devices, Business plan
Browser note: Use Chrome, Edge, or Safari. Open the file directly in the browser — not in the Files app on iPhone.
03

Add to home screen (mobile) All plans

1
iPhone / iPad — Safari only
Open your URL in Safari. Tap the Share button (box with arrow). Scroll and tap Add to Home Screen. Name it "Expenses" → Add.
Must use Safari. Chrome on iPhone does not support Add to Home Screen.
2
Android — Chrome
Open your URL in Chrome. Tap ⋮ (three dots) → Add to Home screen → Add. The app icon appears on your home screen and opens full-screen like a native app.
04

Host on GitHub Pages All plans

1
Create a free GitHub account
Go to github.com and sign up for free.
2
Create a new repository
Click + → New repository. Name it expenses. Set to Public. Click Create repository.
3
Upload the file
Click uploading an existing file. Drag Servly_Expenses.html in. Rename it to index.html before uploading. Click Commit changes.
Important: File must be named index.html for GitHub Pages to serve it.
4
Enable GitHub Pages
Go to Settings → Pages. Source: Deploy from a branch. Branch: main, folder: / (root). Click Save.
5
Get your URL
After 1–2 minutes: yourusername.github.io/expenses is live. Share this with your staff. Bookmark it on every device.
Note: Each device has its own localStorage — expenses logged on one device don't sync to another automatically. Business plan users can use Google Sheets sync to centralize data. All users can export CSV and consolidate manually.
05

Logging your first expense All plans

1
Click "Add Expense"
Top-right button on any page. On mobile, tap the + floating button above the bottom tab bar.
2
Fill in the form
Date — today by default. Change for past expenses.
Amount — pesos, decimals supported.
Description — what you bought (e.g. "Syringes and needles").
Category — pick from your categories.
Payment type — Cash, GCash, Card, Bank Transfer, Maya.
Notes — optional. Supplier name, receipt number.
3
Click Save
The expense saves instantly. Dashboard updates in real time. No internet needed.
Edit or delete: Go to the Expenses page. Click the ✏ pencil to edit or the 🗑 trash icon to delete any entry.

Budget limits & alerts Pro Business

Set a monthly spending cap per category. When you exceed it, a red alert bar appears on the dashboard and the category shows an over-budget warning.

1
Go to Categories
Click Categories in the sidebar (or bottom nav on mobile).
2
Set a budget for any category
Next to each category, tap the budget field and enter a monthly limit (e.g. ₱5,000 for Supplies). Leave blank for no limit.
3
Watch the alerts
The dashboard shows a progress bar per category. When spending exceeds the budget, the bar turns red and a badge appears. Resets automatically each month.
07

Recurring expenses Pro Business

Set up monthly fixed costs — rent, internet, software subscriptions — once. The app reminds you to log them and can auto-create the entry on the due date.

1
Open Add Expense → mark as Recurring
When adding any expense, toggle Recurring monthly. Set the day of month it recurs (e.g. day 1 for rent).
2
View recurring list
Go to Categories → Recurring tab to see all active recurring expenses, their next due date, and how many months they've been logged.
3
Dashboard reminder
On the due date, a Recurring due today banner appears on the dashboard with one-tap logging.

Branches & staff Business

1
Go to Business tab
Click Business in the sidebar or bottom nav. You'll see Branch Management, Staff, Approvals, Sheets Sync, and Branding sections.
2
Add your branches
Click + Add Branch. Name each location (e.g. "Main Clinic", "Makati Branch"). Each branch gets a color. Click its pill to switch to it — all expenses you log are tagged to the active branch.
3
Add staff members
Click + Add Staff. Enter name and role (e.g. "Ana Cruz — Cashier"). When logging an expense, you can assign it to a staff member. Filter by staff on the Expenses page.
Tip: Each device has its own localStorage. For true multi-device branch sync, set up Google Sheets sync (Section 09) — all branches push data to one central sheet.
09

Google Sheets sync Business

Sync all your expenses to a Google Sheet with one click. Your accountant can access the sheet, run their own formulas, or pull it into their own reporting tools.

1
Open Google Sheets
Create a new blank Google Sheet. Name it Servly Expenses.
2
Open Apps Script
Click Extensions → Apps Script. Delete all existing code in Code.gs.
3
Paste the GAS file
Open Servly_Expenses_GAS.gs from your delivery package. Copy the entire contents and paste it into Apps Script. Click Save (Ctrl+S / Cmd+S).
4
Deploy as Web App
Click Deploy → New deployment.
Type: Web app.
Execute as: Me.
Who has access: Anyone.
Click Deploy. Authorize when prompted.
Copy the Web app URL it gives you.
Keep this URL private. Anyone with it can write to your sheet.
5
Paste URL in Servly Expenses
Go to Business → Google Sheets Sync. Paste your Web App URL in the field. Click Save URL then Sync Now.
6
Check your sheet
All expenses appear in a tab called Expenses. Categories appear in Categories. Run Sync Now any time to push updates.
Re-deploy after changes: If you edit the GAS file, go to Deploy → Manage deployments → edit → New version → Deploy. The URL stays the same.
10

Approval workflow Business

Staff submit expenses that a manager reviews before they're counted in reports. Useful for petty cash control or verifying purchase claims.

1
Staff: submit an expense for approval
When adding an expense, toggle Submit for approval. The expense is saved as Pending — it appears in reports with a pending badge but is excluded from totals until approved.
2
Manager: open Pending Approvals
Go to Business → Pending Approvals. Each pending expense shows: staff name, description, amount, date.
3
Approve or reject
Click ✓ Approve to accept — expense is now counted in all totals. Click ✕ Reject to remove it permanently.

Exporting data & PDF reports All plans

A
Export all expenses as CSV
Click Export CSV in the sidebar. Downloads every expense ever logged. Open in Excel or Google Sheets.
B
Export a period report as CSV
Go to Reports. Select a month and year. Click Export report — downloads only that period. Ideal for monthly accountant submissions.
C
Export as PDF Business
Go to Business → PDF Report Export. Set a date range (or click This month). Click Export PDF — a print-ready page opens. Use your browser's Print → Save as PDF. Includes your branding color, category breakdown, and full expense table.
Monthly habit: Export a CSV at the end of every month and save to Google Drive. This gives you a permanent backup and an easy file to send your accountant.
12

Backing up your data All plans

Servly Expenses stores data in your browser's localStorage. This data persists between sessions but can be lost if you:

  • Clear your browser's site data or cache
  • Switch to a different browser or device
  • Reinstall the browser
Best practice: Export a CSV every month and save it to Google Drive. Business plan users: run Sync Now weekly to keep your Google Sheet current. This is your insurance policy.

Do not use your browser's "Clear all site data" setting for the domain where Servly Expenses is hosted — this will erase your data. If you need to clear cache, use "Clear cached images and files" only, not "Cookies and site data".

Troubleshooting

My data disappeared after clearing the browser
localStorage was cleared. Restore from your CSV backup by using Import CSV on the Expenses page. This is why monthly CSV exports are strongly recommended.
The app shows no expenses on a different device
Each browser on each device has its own localStorage — data doesn't sync automatically. Business plan: use Google Sheets sync to centralize. All plans: export CSV from one device and import on another.
Charts don't appear (blank canvas)
Charts load Chart.js from a CDN — they need internet on first load. After the first load with internet, they're cached. If you're offline and charts are blank: open the app once while connected, then it works offline from then on.
Google Sheets sync says "Network error"
Check that: (1) your GAS file is deployed as a Web App, (2) Access is set to "Anyone", and (3) you copied the full URL including https://. If you edited the GAS file, you must re-deploy (Deploy → Manage deployments → New version).
Add to Home Screen doesn't appear on iPhone
You must use Safari — not Chrome, not Edge. Open the URL in Safari → Share button → Add to Home Screen.
Import CSV isn't working — "no data rows" error
Your CSV must have at least these columns: Date, Description, Amount. Column headers must be in the first row. Dates must be in YYYY-MM-DD format. Export a sample from Servly Expenses and compare it to your import file.
